No True Project Team

No True 项目组

英文名：No True Project Team。No True 项目组是本站的发起与维护团队，负责作品征集、内容规范、审核协调与网页展示。

创作与维护方向

项目组希望为学生提供一个可以认真表达奇想的空间：允许荒谬作为问题的开端，同时要求论述具有基本逻辑、尊重他人，并遵守伦理与法律规范。团队的工作不是替作者给出唯一答案，而是让每一份展示内容有清晰的边界与可讨论的价值。
